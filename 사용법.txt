RFVisualizer 웹 프레젠테이션

1. index.html을 더블클릭하면 인터넷 연결 없이 바로 실행됩니다.

2. 발표 조작
   - 다음/이전 장면: 방향키, Page Up/Down, 마우스 휠
   - 발표자 대본: N
   - 전체화면: F   (전체화면에서는 상단바와 우측 레일이 숨겨집니다)
   - 레이저 포인터: L  (한 번 더 누르면 꺼집니다. Esc로도 꺼집니다)
     켜면 마우스 커서가 사라지고 빨간 레이저 점이 포인터를 따라갑니다.
   - 첫/마지막 장면: Home/End
   - 이미지 확대: 이미지 클릭

3. 화면 구성
   슬라이드는 1600x900 고정 캔버스에 그려지고, 화면 크기에 맞춰 통째로
   축소됩니다. 따라서 프로젝터 해상도나 화면 비율이 달라도 지금 보는
   그대로 나옵니다. 내용이 캔버스를 넘치면 잘리므로, 글을 크게 늘릴 때는
   해당 슬라이드를 한 번 확인해 주세요.

4. 수정 위치
   - 화면 문구와 대본: index.html
   - 색상과 레이아웃: styles.css
   - 장면 이동, 캔버스 배율, 쪽번호: app.js
   - 사진 교체: assets 폴더

5. 사진/영상 자리(Placeholder) 채우기
   점선 상자로 표시된 자리에 아직 사진이나 영상이 들어가지 않았습니다.
   상자 안에 채워 넣을 파일 이름이 적혀 있습니다.

     08 모니터링      assets/monitor.png  또는 monitor.mp4
     14 시연 영상 1   assets/demo-methods.mp4
     15 시연 영상 2   assets/demo-pose-viewer.mp4 / demo-pose-device.mp4
     16 시연 영상 3   assets/demo-buttons.mp4 / demo-relay.mp4

   파일을 assets 폴더에 넣은 뒤, index.html에서 해당 자리의

     <div class="media-slot"> ... </div>

   블록을 통째로 아래 중 하나로 바꾸면 됩니다.

     영상:  <video class="media-fill" src="assets/demo-methods.mp4"
                   controls muted loop playsinline></video>

     사진:  <img class="media-fill" src="assets/monitor.png" alt="모니터링 화면" />

   media-fill 클래스가 상자 크기에 맞춰 여백 없이 채워 줍니다.
   발표 중 자동 재생을 원하면 video 태그에 autoplay 를 추가하세요.

6. 동작 줄이기(Reduce motion)가 켜진 기기
   운영체제의 "동작 줄이기 / Reduce motion" 설정이 켜져 있으면 브라우저가
   모든 전환을 사실상 0으로 만듭니다. 그대로 두면 등장 연출이 순식간에
   지나가 화면이 튀어 보입니다.

   그래서 그런 기기에서는 이동(흔들림)만 빼고 페이드는 0.28초로 남기도록
   해 두었습니다. 설정 위치는 다음과 같습니다.

     macOS   시스템 설정 > 손쉬운 사용 > 디스플레이 > 동작 줄이기
     Windows 설정 > 접근성 > 시각 효과 > 애니메이션 효과
     iOS     설정 > 손쉬운 사용 > 동작 > 동작 줄이기
     Android 설정 > 접근성 > 애니메이션 제거
