3 측정과 분석 · 개념

시뮬레이션과 실측, 둘 다 필요함

각각 혼자서는 놓치는 것이 있고, 놓치는 지점이 서로 다름

① 시뮬레이션만 Sionna RT

복원한 공간에서 전파가 벽에 부딪히고 꺾이는 경로를 물리적으로 계산

놓치는 것 벽 재질과 문이 열렸는지를 정확히 모름. 값이 통째로 치우침

② 측정만 Plain IDW

실제로 잰 값만 사용. 가까운 측정점에 더 큰 가중치를 주어 빈 곳을 채움

놓치는 것 재지 않은 곳의 벽과 차폐를 모름. 벽을 통과해 값이 번짐

③ 둘을 합침 Residual IDW · 제안

보정점에서 잔차 = 실측 − 예측을 구하고, 그 차이를 공간에 퍼뜨려 예측에 더함

얻는 것 공간 구조는 시뮬레이션이, 현장 오차는 실측이 담당

비교군 - Global Bias 보정점 오차의 평균 하나를 공간 전체에 똑같이 더하는 가장 단순한 보정

3 측정과 분석 · 이유

오차의 부호가 서로 반대

  • 송신기가 보이는 곳에서는 시뮬레이션이 실제보다 높게 예측 · 평균 -11.66 dB
  • 벽에 가린 곳에서는 반대로 낮게 예측 · 평균 +4.27 dB
  • 부호가 반대라 전체에 같은 값을 더하면 한쪽이 반드시 나빠짐. Global Bias가 실패한 이유
  • 남은 한계: 잔차를 직선 거리로 퍼뜨리므로 벽 너머로 번짐. 오른쪽 붉은 영역
